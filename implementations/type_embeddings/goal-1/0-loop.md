# Working rhythm

1. Sync `0-plan.md` with the actual files, compiled results, decisions, and the revised
   `type_value_embeddings_revised_proposal.md`. Inspect source changes before claiming
   existing results cover them; record material differences in `docs/REVISION.md`.
2. Select the first unfinished stage. Follow `implementations/BUILD-PLAN.md` for stage records, narrow modules, and focused builds.
3. Take the actions that directly advance that stage using current evidence and judgment.
4. Validate important outcomes with suitable Lean builds, theorem review, and actual
   axiom checks. Treat experiments and mathematical verification as different evidence.
5. Record material corrections and changed assumptions in `docs/AUDIT.md`, update the
   proposal/declaration map, and fold stage status and decisions into `0-plan.md`.
6. Continue toward the full objective while preserving scope and directory constraints.
7. At session end, leave a short handoff with the next action and any real blockers.

Prioritize delivered mathematical results over ceremony. Let evidence guide design;
keep records concise and useful; match completion claims to observed checks.
