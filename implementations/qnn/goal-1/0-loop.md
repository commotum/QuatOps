# Working rhythm

This loop applies only after explicit authorization to continue beyond scaffolding.

1. Sync `0-plan.md` with actual files, results, and completed work.
2. Select the first unfinished stage.
3. Take the actions that most directly advance it, guided by current evidence and
   best judgment; choose implementation details from the actual library state.
4. Confirm important outcomes with checks appropriate to their acceptance criteria:
   pinned Lean build, exact hypotheses, source correspondence, and actual axiom output.
5. Record material findings, corrections, decisions and stage status in `0-plan.md`
   and the relevant concise supporting document.
6. Continue through stages toward the full original objective, adapting the strategy
   when evidence warrants it without weakening correctness or changing scope silently.
7. If a session ends mid-goal, leave a short state note and concrete next action.

Prioritize meaningful progress. Preserve the objective and constraints. Match
completion claims to observed evidence; empirical claims and unsupported learning
claims never count as proved mathematical results. Keep records useful and compact.
